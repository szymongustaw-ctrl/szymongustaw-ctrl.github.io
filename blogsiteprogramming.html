My Experience With Programming

| Szymon Grześkowiak |Created on 07.10.2026 |

My First Steps in Programming:

My first steps in programming were in primary school, where I learned the basics of C++. Although I only learned the basics, it gave me my first contact with code and helped me understand how it works. Later, I learned Python by myself to prepare for my final exams in secondary school. This helped me develop my programming skills and become more familiar with programming concepts.

Using Programming Outside School:

Despite I only had programming lessons in primary school, I decided to learn Python on my own. I used it to create small programs that made everyday tasks easier. For example, I wrote programs that calculate given formula instead of calculating it manually. I also used Python to create macros and automation scripts. These saved me a lot of time and were fun to make. These projects were not complicated, but they taught me that programming is not only about writing code, but also about finding practical solutions to problems.

My Current Use of Programming:

At the moment, I am studying ICT, where I am learning how to program in JavaScript. Because it is quite similar to python, which makes it easier for me to understand. I really enjoy learning a new programming language. I hope to improve my programming skills and use them to create more complex projects than before.
