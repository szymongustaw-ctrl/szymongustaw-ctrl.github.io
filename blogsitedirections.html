My Direction: Backend Development

|Szymon Grześkowiak|Created on 19.10.2026 |

Why I Chose Backend Development:

I have been interested in IT since I was a child. My dad inspired me by showing me computer hardware and introducing me to technology. At school, I was often the person who helped when something broke in class. Later, I became more interested in programming, especially after gaining experience with Python. I really like technology and solving problems, which is why I would like to become a backend developer. I am interested in understanding how software works behind the scenes and how different parts of a system communicate with each other.

What Is Backend Development:

Backend development focus on the parts of a website or application that user do not see. Backend developers work with server side code, databases and application logic. They make sure that data is processed correctly and that applications work as they should. For example, backend development is used in login systems, banking applications and more.

Skills I Want to Improve:

To become a backend developer, I need to improve my programming skills and learn how to create software. I want to gain more experience with Python and learn about APIs and server side programming. I also want to improve my problem-solving skills and learn how to write good quality code. In addition, I am interested in understanding how frontend development works to improve my backend skills

My Future as a Backend Developer:

In four years, I see myself working as a backend developer in a company where I can gain practical experience and improve my programming skills. I would like to learn from experienced developers and work on real projects to understand how professional software is built. My goal is to become a independent backend developer. I want to keep learning new technologies, take more challenging projects and build more complicated software .
